Mimi 抖音

独立运行，本页不需要 AstrBot。

先配置模型

先填聊天接口，再选择能看视频、图片和音频的模型。视频接口留空时使用同一地址和密钥，模型名称仍需填写。

视频使用另一家接口

更换聊天风格后使用独立的历史范围，避免继续引用旧风格的对话。

这是发到抖音评论区的公开留言。关闭后仍可刷作品、读取内容和私聊。

手动指定程序位置

通常留空自动查找；只有检测不到已安装程序时再填写。

检查运行依赖

已有程序会自动识别。缺 Node 或 FFmpeg 时先安装对应程序；Playwright 和可选 Chromium 可以在这里安装。

组件状态位置与说明

登录和绑定

  1. 打开登录窗口，用机器人账号登录抖音，进入你们的私信。
  2. 绑定当前私信，只记录当前历史，不补回旧消息。
  3. 开启回复，再用自己的账号发一句话试试。

自己刷一条

打开自主活动开关后可在这里试读推荐作品。正常定时触发时，Mimi 可以选择聊天、刷作品或读完再聊天。



给刚读过的作品留言

需要开启上方评论开关；只有得到服务器评论 ID 才算成功，未知结果不会自动重发。
