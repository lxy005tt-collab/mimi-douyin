# Mimi 抖音

在本机运行一个抖音聊天助手：回复私信，实际读取分享的视频、图文和作品简介，也可以自己刷推荐。
本仓库发布独立运行版。下载 [Windows 使用包](https://github.com/lxy005tt-collab/mimi-douyin/releases/latest)，解压后按下面的步骤安装。

请自行准备支持视频输入的模型，已经配备视频转文本接口。

私信分享视频给它看已经完整测试可用，bot 自己刷视频仍然在测试中不稳定性未知

## 能做什么

- 回复当前绑定的抖音私信，支持白名单。
- 读取分享视频的完整画面，单独提取音轨核对对白。
- 按顺序读取图文里的原图，避免只看封面就说自己读完了。
- 把作品简介、画面字幕、声音分别提供给聊天模型。
- 让 Mimi 自己刷推荐作品，也可以读完再找你聊天。
- 开启评论开关后，在实际读过的作品下留言。只有拿到服务器返回的评论 ID，才算发出；结果不明确时不自动重发。

目前发送文字消息。图片和视频会先保存到本机，再交给你配置的模型处理。

## 先准备这些

| 需要什么 | 用来做什么 | 怎么准备 |
| --- | --- | --- |
| Python | 运行独立版 | 从 [Python 官网](https://www.python.org/downloads/)安装受支持的版本。本机验证用的是 Python 3.12。 |
| Node.js 和 npm | 连接浏览器 | 从 [Node.js 官网](https://nodejs.org/en/download)选择 LTS 版本。程序最低要求 Node.js 20。 |
| Edge 或 Chrome | 登录抖音、读取页面 | 已经装了就直接用；也可以在设置页下载单独的 Chromium。 |
| FFmpeg 和 FFprobe | 检查视频、压缩文件、提取音轨 | 从 [FFmpeg 下载页](https://ffmpeg.org/download.html)选择自己系统的安装包。Windows 下载可运行的构建包，不要下载源码包。 |
| 模型接口 | 聊天、看视频和图文 | 准备接口地址、密钥、聊天模型名、视频模型名。它们不包含在发布包里。 |
| 机器人抖音账号 | 接收和回复私信 | 首次使用需要自己登录。 |

Windows 可以把程序放到 `D:\Tools\MimiDouyin`。Python、Node 和 FFmpeg 也可以装在 D 盘，不要求使用某个固定位置。

FFmpeg 安装包里应同时有 `ffmpeg.exe` 和 `ffprobe.exe`。把它们所在目录加入 PATH，或者在设置页手动填写程序路径。只聊文字时不需要这两个程序；看视频和核对声音时需要。

## 独立运行：Windows

1. 把独立版压缩包解压到一个固定目录，例如 `D:\Tools\MimiDouyin`。
2. 安装上面列出的 Python 和 Node.js。安装 Python 时保留 Python 启动器，确保命令行能用 `py`。
3. 双击 `setup.bat`，等依赖安装完成。首次安装会联网下载 Python 依赖，在当前目录创建自己的 `.venv`。
4. 双击 `start.bat`。这个窗口要保持运行，关掉后程序就停止了。
5. 用浏览器打开终端显示的地址，默认是 `http://127.0.0.1:8787`。

`setup.bat` 只在首次安装或更新依赖时运行。平时双击 `start.bat` 即可。

如果你习惯用命令行，也可以在解压目录运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r standalone-requirements.txt
.\.venv\Scripts\python.exe -m mimi_douyin serve --data-dir .\data
```

## 独立运行：Linux 或 macOS

在项目目录运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r standalone-requirements.txt
.venv/bin/python -m mimi_douyin serve --data-dir ./data
```

浏览器首次登录需要图形桌面。纯命令行服务器或 Docker 不能直接扫码，需要先准备桌面、VNC 或 X11；Linux 的 Chromium 还可能需要系统库，按 [Playwright 官方说明](https://playwright.dev/docs/browsers)安装。程序不会自动执行提权安装。

目前实际验证以 Windows 为主，Linux 和 macOS 的账号登录仍需自行检查。

## 第一次打开设置页，按这个顺序来

### 1. 填模型接口

填好聊天接口地址、密钥和模型名称，地址通常是服务商提供的、以 `/v1` 结尾的接口根地址，不是网页地址，也不是完整的 `/chat/completions` 地址。

再填看视频和图文的模型名称。它可以和聊天模型不同。视频如果用另一家接口，就展开“视频使用另一家接口”，单独填地址和密钥；使用同一份密钥时，勾选对应选项。

点击“保存设置”，再点“测试聊天接口”。测试成功只说明聊天接口能连通，不代表所选视频模型一定能接收视频。

密钥保存后不会回显。密钥框留空会保留已有值，换密钥时直接填新的。

### 2. 选择保存目录，检查依赖

点击“选择文件夹”，选视频和图文要保存的位置，再保存设置。选的是运行程序的电脑上的目录，不是访问设置页的手机本地目录。

留空时使用数据目录里的 `media`。更换目录只影响新文件，已有视频和登录资料不会搬动或删除。想新建目录，也可以直接输入完整路径后保存。

查看依赖表：

- Node、FFmpeg、FFprobe、浏览器会自动查找。
- 缺 Playwright 时，点击“安装浏览器连接组件”。这是连接浏览器的程序包，会装在本项目数据目录里。
- 已有 Edge 或 Chrome 就不必再下载浏览器。没有时再点击“下载 Chromium 浏览器”。

重新检测不会自动下载。刚装完程序却检测不到，可以重启本程序，或展开手动路径设置，直接填写程序位置。

### 3. 登录、绑定、开启回复

点击“打开登录窗口”，用机器人的抖音账号登录。点“消息”，进入你和机器人的私信。

如果这是新建的私信，先用机器人账号手动回一条普通文字，让页面里有双方的消息，再绑定。

然后回到设置页，点“绑定当前私信”，核对对象，再点“开启回复”。绑定只记录当前历史，不会补回旧消息。

第一次绑定会把当前对象加入白名单。白名单开启但为空时，所有人都不能触发回复。

接着用自己的账号给机器人发一句话，先确认文字正常，再分享一条视频或图文。

### 4. 想让她自己刷，再开自主活动

勾选“允许 Mimi 主动聊天或自己刷抖音”，设置活动间隔后保存。也可以点击“实际读一条推荐作品”先试一次。

定时触发后，她可以选择找你聊天、自己读一条作品，或者读完再聊。只有真正取得媒体内容并完成转述，才会登记为读过。

公开评论是单独的开关，默认关闭。不打开评论开关，仍然可以看作品和私聊。打开后，她只能评论本程序实际读取过的作品。

## 与 AstrBot 的关系

本仓库只包含独立运行版，不包含 AstrBot 适配插件或其主动回复补丁。独立版的私信、媒体转述和自主活动都由自己的程序运行，不依赖 AstrBot、QQ 或 LivingMemory。

如果同一抖音账号已经接入其他机器人，先暂停另一套监听，再启动本程序。

## 聊天记录和记忆放在哪里

独立版默认把数据保存在启动时指定的 `data` 目录：

- `config.json`：模型和程序设置，含密钥，不要上传或分享。
- `messages.db`：聊天历史、观看记录和发送状态。
- `media`：实际下载的视频、图片和提取的音轨。
- `browser-profile`：浏览器登录资料，不要打进发布包。
- `runtime`：安装的 Playwright、可选 Chromium 和安装日志。

独立版更换聊天风格后使用另一组历史范围，旧记录仍保留。它不会自动读取或迁移 AstrBot 的人格、QQ 聊天和长期记忆。

图文只依据实际下载的图片和已取得的声音说明内容。没有取得图文配乐时，会明确说明未提供音频。

## 常见问题

**必须一直把私信放前台吗？**

不用一直放前台，但专用窗口里的目标私信要保持打开。启动时会尝试恢复绑定会话；页面关闭、登录失效或恢复失败时，需要手动处理。当前版本不会轮巡所有私信。

**浏览器为什么会弹到前面？**

可见浏览器的自动操作可能抢焦点。程序已减少回复时的鼠标操作，读取作品使用后台标签页；实际效果仍受浏览器和网页影响。首次登录会显示窗口。无头模式可能触发抖音验证码，不适合直接当作默认解决办法。

**看起来登录了，却一直读不到消息？**

检查是否停在验证码或安全验证页面，再确认已经进入正确私信。程序不会代你完成账号验证。

**只读出了标题，或者说视频转述失败？**

先确认视频模型和接口真的支持媒体输入。只有封面或标题不算读取视频；图文取不到原图、视频没有画面轨道或文件不完整时，程序会报告失败，不会编造内容。

感知接口调用失败时，会在本次超时限额内再试一次；参数或鉴权错误不重试。识别成功后会缓存转述，同一作品再次分享时可直接复用。回复发送和评论提交结果未知时，仍不会自动重发。

**浏览器静音会影响识别声音吗？**

不会。声音从实际下载的文件提取，不录制电脑正在播放的声音。

**为什么评论没有发出去？**

检查评论开关、作品是否已实际读取，以及抖音是否要求验证。页面控件识别不明确时会停止提交。没有收到评论 ID 的结果会记为失败或未知，不能当作已发出，也不会自动重发。

**怎么停止？**

先在设置页暂停回复。独立版在启动窗口按 `Ctrl+C` 停止；下次运行 `start.bat` 再打开设置页即可。

## 自己接模型接口或发布源码时

视频和聊天都使用兼容的聊天请求接口。视频感知还需要接口接收 `video_url`，图文使用 `image_url`，独立音轨使用 `file.file_data` 音频文件内容块。模型名称里有 Gemini，并不代表服务商一定开放了这些输入。只提供文字或图片输入的接口，不能替代完整的视频接口。

源码可用 `python -m pip install .` 安装，命令行入口为 `mimi-douyin`。核心包是 `mimi_douyin`，可以不安装 AstrBot；根目录的 AstrBot 入口只是可选适配。需要检查本机依赖时可运行 `python -m mimi_douyin check --data-dir ./data`。

发布时只打包源码、静态页面、依赖说明和示例配置，不带 `data`、`.venv`、`node_modules`、密钥、聊天库或登录资料。浏览器选择器参考来源和第三方许可见 [ATTRIBUTIONS.md](ATTRIBUTIONS.md)。
